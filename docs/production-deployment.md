# Production deployment

Deploy the single image behind an enterprise MCP gateway, or expose the Streamable HTTP endpoint through a trusted TLS reverse proxy. Use PostgreSQL with TLS, encrypted disks, restricted backups, and a dedicated role. Run `shadow-ai migrate` once per release, then `shadow-ai serve`. Keep the connector and registry YAML files read-only. Run one worker process or rely on PostgreSQL advisory locks if scaling web processes; size ingestion and DB retention for log volume.

Set `SHAI_AUTH_MODE=jwt`, issuer, audience, and HTTPS JWKS URL for direct bearer validation. For gateway identity headers, set `SHAI_AUTH_MODE=gateway`, trusted gateway CIDRs, and a secret environment variable name. The gateway must authenticate users, remove client-supplied identity/assertion headers, set identity and scopes, and sign `identity|scopes|unix_timestamp` using HMAC-SHA256 into the assertion header. The server checks peer IP, freshness within 60 seconds, and constant-time signature equality. Do not trust `X-Forwarded-For` as a peer identity. Set `SHAI_ALLOWED_HOSTS` to the externally served host and port. Bind the service to a private interface. Development mode must remain false.

Give connectors query-only credentials and require HTTPS endpoints. Inject credentials via a secret file or short-lived environment value; do not place them in images, YAML, Compose, or database rows. Configure provider mappings, known shared egress IPs, authorized direct-route exceptions, poll windows, retention, and freshness thresholds against real log delay. Review each connector's event coverage before drawing negative-evidence conclusions.

Monitor `/readyz`, connector health, telemetry age, detection duration, MCP latency, auth failures, and PostgreSQL health. Restrict `/metrics` to local scraping or a trusted internal collector. Export audit events to an immutable enterprise sink. Back up registry source files and database with a recovery procedure. There is no multi-tenant row isolation; deploy separately for separate trust domains. Validate the gateway and source adapters against live enterprise endpoints before production use.
