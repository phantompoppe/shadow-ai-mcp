# Browser demo with GitHub Codespaces

Open [the repository's Codespaces page](https://codespaces.new/phantompoppe/shadow-ai-mcp?quickstart=1) while signed in to `phantompoppe` (or an account granted access to the private repository). Create or resume a codespace on `main`. Its dev container installs Python dependencies and starts the fixture demo when the browser editor attaches. GitHub forwards port 8000. In the editor's **Ports** tab, verify visibility is **Private**, then click the address for **Shadow AI investigation UI**. A visit to the forwarded root redirects to `/ui/`. The UI shows findings, deterministic explanations, approval lookup, and telemetry health. It runs with fixture data only; no enterprise secrets or live connector credentials are needed.

The launcher binds to container loopback, restricts development identity to loopback clients, and allows the exact forwarded host for the MCP transport. GitHub's private forwarded ports require the codespace creator's GitHub authentication. Do not change the port to Public: the fixture server uses development authentication and is intended only for a private codespace. Production deployment uses gateway assertions or validated JWTs and PostgreSQL.

If automatic startup fails, open a Codespaces terminal, inspect `/tmp/shadow-ai-codespaces-demo.log`, and run `bash scripts/codespaces-demo.sh` again. The launcher is safe to rerun after the server becomes ready. For a clean fixture database, stop the server, remove `shadow-codespaces.db`, then rerun the launcher. When finished, stop the codespace from GitHub's Codespaces page to avoid leaving compute running. Codespaces uses your account's included compute/storage allowance and may cost money beyond that quota.

If cloning locally instead, use the plain command `git clone https://github.com/phantompoppe/shadow-ai-mcp.git`. Do not include Markdown link syntax (`[text](url)`) in a terminal command. Because the repository is private, your local Git installation must authenticate as an account with repository access. The browser demo avoids local Git, Docker, and Python installation.
